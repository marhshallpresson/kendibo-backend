# Kendibot language evaluation

Kendibot uses an in-process intent classifier and can call a configured generative provider with shared server-owned tools and instructions. Sending instructions or examples in a prompt does not retrain Gemini, Anthropic or another hosted model, and adding examples to the local classifier does not change their weights. Providers must be evaluated separately.

Run `npx tsx --import dotenv/config scripts/eval-kendibot-live.ts --live` to make two synthetic, billable Gemini smoke-test requests. They contain no customer data and check only whether the adapter receives a relevant structured tool call for one Nigerian Pidgin and one English example. A pass is not evidence of conversational fluency, production delivery, broad language support or model training. The adapter may use the configured fallback; the result identifies the model that emitted the tool call. This script never executes the model's tool calls or sends WhatsApp messages.

For a representative evaluation, collect examples with explicit permission from speakers and operators in the launch area, remove unnecessary personal data, and have independent reviewers agree on each label. Keep a frozen evaluation set separate from training and prompt tuning, grouped by person and conversation. Include English, Nigerian Pidgin, spelling variation, code switching, descriptions, cancellations, status, prices, safety and human hand-off, plus other languages only when reviewed by proficient speakers. Track sample counts, intent and slot accuracy, unnecessary clarifications, wrong actions, safety violations and end-to-end completion separately per language and provider. Compare candidates to the current baseline on the same cases before release; a model must not be promoted merely because a few examples work.

The synthetic classifier candidate in the existing working tree did not meet the earlier promotion gate and should not be mixed into a release without further evaluation. Customer confirmations, pricing, availability, payments and human hand-offs remain server-controlled rather than delegated to a model.
